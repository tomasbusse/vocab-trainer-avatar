# VocabTrainer - AI-Powered English Vocabulary Learning

An interactive English vocabulary trainer featuring an AI avatar teacher (Emma) powered by LiveKit, Beyond Presence, Cartesia, and Convex.

Built by [Simmonds Language Services](https://www.englisch-lehrer.com), English training with native-speaker trainers in Hannover, Berlin and online since 2004. Free English lessons and worksheets: [englisch-lehrer.com/en/lessons](https://www.englisch-lehrer.com/en/lessons).

## Features

- **AI Avatar Teacher**: Real-time video avatar with natural conversation
- **4 Practice Modes**:
  - Conversation: Chat naturally with Emma
  - Flashcards: Quick word review
  - Quiz: Multiple choice challenges
  - Pronunciation: Speaking practice with feedback
- **Individual Student Links**: Unique URLs for each student
- **Progress Tracking**: Mastery levels, streaks, and statistics
- **Adaptive Difficulty**: Adjusts based on performance
- **Mobile-First Design**: Works great on phones and tablets

## Tech Stack

- **Frontend**: Next.js 15, React 19, TailwindCSS 4
- **Backend**: Convex (real-time database)
- **Voice Agent**: LiveKit Agents (Python)
- **Avatar**: Beyond Presence Genesis
- **TTS**: Cartesia Sonic Turbo
- **STT**: Deepgram Nova-3
- **Auth**: Clerk (optional)
- **Deployment**: Vercel + LiveKit Cloud

## Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Set Up Convex

```bash
# Create a new Convex project
npx convex dev --once --configure=new

# This will:
# - Create a new project on Convex
# - Generate your deployment URL
# - Add it to .env.local
```

### 3. Configure Environment Variables

Create `.env.local`:

```env
# Convex (auto-generated by convex dev)
CONVEX_DEPLOYMENT=your-deployment
NEXT_PUBLIC_CONVEX_URL=https://your-project.convex.cloud

# LiveKit
LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=your-api-key
LIVEKIT_API_SECRET=your-api-secret

# Beyond Presence
BEY_API_KEY=your-bey-api-key
BEY_AVATAR_ID=your-avatar-id

# Cartesia
CARTESIA_API_KEY=your-cartesia-key

# Deepgram
DEEPGRAM_API_KEY=your-deepgram-key

# OpenAI (or OpenRouter)
OPENAI_API_KEY=your-openai-key

# Clerk (optional)
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your-clerk-key
CLERK_SECRET_KEY=your-clerk-secret
```

### 4. Run Development Server

```bash
# Terminal 1: Run Next.js
npm run dev

# Terminal 2: Run Convex
npm run convex:dev

# Terminal 3: Run LiveKit Agent (optional for avatar)
npm run agent:install  # First time only
npm run agent:dev
```

### 5. Open in Browser

Visit `http://localhost:3000`

## Deployment

### Deploy to Vercel

1. Push to GitHub:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/yourusername/vocab-trainer.git
git push -u origin main
```

2. Import to Vercel:
   - Go to https://vercel.com/new
   - Import your GitHub repository
   - Add environment variables
   - Deploy

3. Deploy Convex:
```bash
npx convex deploy
```

### Deploy LiveKit Agent

The Python agent needs to run on a server with Python 3.12+:

```bash
# On your server
cd agent
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python vocab_agent.py start
```

Consider using:
- LiveKit Cloud for managed agent hosting
- Railway, Render, or a VPS for self-hosting

## Creating Student Links

Each student gets a unique link:

```
https://your-app.vercel.app/train/abc123xyz
```

To create links programmatically:

```typescript
import { useMutation } from "convex/react";
import { api } from "@/convex/_generated/api";

const createSession = useMutation(api.sessions.create);

const { accessToken } = await createSession({
  trainerId: trainerId,
  studentName: "John Doe",
});

const studentLink = `https://your-app.vercel.app/train/${accessToken}`;
```

## Customization

### Adding Words

Edit `convex/curriculum.ts` to add more vocabulary, or use the teacher portal to create custom word lists.

### Changing Avatar

Update `BEY_AVATAR_ID` in your environment variables with your Beyond Presence avatar ID.

### Styling

The theme uses:
- Primary: `hsl(152, 60%, 35%)` (Medium dark green)
- Background: White
- Accents: Shades of grey

Edit `src/app/globals.css` to customize.
